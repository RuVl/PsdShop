# PsdShop

Витрина цифровых товаров: покупатель оплачивает заказ криптовалютой через Plisio и получает по
почте ссылку на страницу покупок, откуда скачивает файлы. Товар — шаблон документа, один и тот же
файл продаётся неограниченное число раз ([ADR-0001](./docs/adr/0001-unlimited-copies-no-reservation.md)).

Термины ниже — язык предметной области, а не имена таблиц. Витрина показывает покупателю страны,
типы документов и годы; модель данных не знает, что именно нарисовано в файле, чтобы линейку
товаров можно было сменить без переписывания схемы.

## Каталог

**Product**:
Позиция каталога: название, описание, цена, файл, картинки, год. То, что покупают.
_Avoid_: Item, Goods, Template

**Country**:
Страна документа. Даёт витрине левый сайдбар со счётчиком и флаг на карточке.
_Avoid_: Category, Group, Region

**DocumentType**:
Тип документа — utility bill, bank statement, tax. Бейдж на карточке и фильтр.
_Avoid_: Category, Kind, Card

**ProductImage**:
Одна картинка товара. Первая по порядку — превью в списке, остальные — галерея карточки.
_Avoid_: Photo, Preview, Attachment

**Active**:
Свойство `Product`, определяющее, виден ли он на витрине. Убрать товар — снять флаг, а не удалить:
файл нужен тем, кто его уже купил.
_Avoid_: Published, Visible, Deleted

**Разрез каталога**:
Пара «страна × тип документа», где `all` означает «любой». Один разрез — один адрес
(`/en/germany/utility-bill/`) и одна страница в карте сайта; пустые разрезы не существуют.
_Avoid_: Фильтр, Категория, Секция

## Витрина

**Shell**:
Собранный vite `index.html` с метой страницы, подставленной сервером. Человек получает его, дальше
работает SPA.
_Avoid_: Index, Template, Layout

**Бот-страница**:
Полный серверный HTML того же адреса, для краулера. Обе подачи строятся из одного queryset и одной
меты — расхождение между ними считается ошибкой (это клоакинг).
_Avoid_: SSR, Пререндер, Статика

## Продажа

**Customer**:
Человек, опознаваемый по адресу почты. Владеет всеми своими заказами, подпиской на рассылку и
языком, на котором с ним говорят письма.
_Avoid_: User, Client, Buyer, Account

**Buyer / lead**:
Покупатель, у которого есть оплаченный заказ, против того, кто дошёл до чекаута и не заплатил.
Различие живёт в `CustomerQuerySet` и определено штампом `Order.paid_at`.
_Avoid_: Active customer, Real customer

**Order**:
Намерение покупателя приобрести набор товаров, вместе с состоянием его оплаты.
_Avoid_: Purchase, Cart, Checkout

**OrderItem**:
Строка заказа: один товар по цене на момент покупки. Она же — единица выдачи: токен скачивания,
срок его жизни и счётчик скачиваний живут здесь.
_Avoid_: LineItem, Position, DownloadLink

**Transaction**:
Инвойс Plisio. У одного заказа их может быть несколько — Plisio создаёт новый инвойс, когда
покупатель меняет криптовалюту.
_Avoid_: Payment, Invoice

## Доступ

**Purchases page**:
Страница, на которой покупатель видит все свои оплаченные заказы и скачивает файлы.
Открывается по токену из письма, без пароля.
_Avoid_: Cabinet, Dashboard, Account page, ЛК

**Access token**:
Секрет в ссылке. Токен `Customer` открывает страницу покупок, токен `OrderItem` — один файл.
Оба имеют срок жизни.
_Avoid_: Key, UUID, Link

## Рассылки

**Broadcast**:
Письмо, отправляемое всем подписанным покупателям.
_Avoid_: Newsletter, Campaign, Mailing

**BroadcastDelivery**:
Факт отправки одного `Broadcast` одному `Customer` с результатом. Делает рассылку
повторяемой без дублей.
_Avoid_: Send, Message, Recipient
