# Каталог: страна, тип документа, год

Витрина (см. `design/index.html`) режет каталог тремя разными способами одновременно:

- **страна** — левый сайдбар «Категории магазина» с флагом и счётчиком товаров, плюс блок
  «Популярные»;
- **тип документа** — бейдж на карточке и радио-фильтр (`utility bill`, `bank statement`, `tax`);
- **год** — второй бейдж и выпадающий фильтр, плюс сортировка по году.

Значит в схеме три разные вещи, а не один список категорий:

| Что | Как | Почему так |
|---|---|---|
| `Country` | модель: `name` (переводится), `code` (флаг), `is_popular`, `position` | Список длинный (80+), редактируется владельцем, нужен счётчик товаров |
| `DocumentType` | модель: `name` (переводится), `slug`, `position` | Типов мало, но они видны в URL фильтра и в бейдже; новый тип не должен требовать миграции |
| `Product.year` | `PositiveSmallIntegerField(null=True)` | Год — свойство файла, а не справочник: он участвует в сортировке и в диапазонах |

Обобщать это в одну модель `Tag` с видами — отказ. Счётчик по стране, сортировка по году и
единственный бейдж типа тогда становятся тремя разными запросами по одной полиморфной таблице,
а фильтры теряют типизацию: год перестаёт быть числом.

## Consequences

- `Product` получает: `slug`, `description` (переводится), `country`, `document_type`, `year`,
  `price`, `file`, `is_active`, `created_at`. Картинки — отдельная модель `ProductImage`
  (`product`, `image`, `position`); первая по `position` работает превью в списке.
- Список стран отдаётся с аннотацией `products_count` (только активные товары) — сайдбар рисует
  счётчик без второго запроса.
- Фильтрация и сортировка — на бэкенде (`?country=&type=&year=&search=&ordering=`), не на клиенте:
  в дизайне фильтры клиентские, но каталог на 80 стран целиком в браузер не поедет.
  Пагинация на витрине обязательна.
- «Популярные» — флаг на стране, а не вычисление по продажам: владельцу нужно управлять этим
  вручную, а не объяснять, почему список меняется сам.
- Флаг на карточке товара берётся из `product.country.code` — отдельного поля «язык документа» нет.
